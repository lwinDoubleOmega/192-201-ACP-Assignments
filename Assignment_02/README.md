# CampusWheels

A Python vehicle-rental program demonstrating classes, encapsulation,
inheritance, and polymorphism.

## How to run

Keep rental.py and main.py in the same folder. Open a terminal
in that folder and run:

python main.py

## AI use

I used ChatGPT/Codex to explain properties, setters, validation,
inheritance, super(), and pytest. AI also reviewed rental.py,
identified bugs, suggested corrections for the classes and main.py.
